Highlights

核心能力

为个人知识沉淀设计，稳定、可替换、隐私友好。

飞书长连接

通过飞书官方 SDK 建立长连接，无需公网域名或 Webhook 回调地址。

幂等归档

使用规范化链接和平台内容 ID 去重，避免重复归档。

AI 输出校验

AI 结果经 JSON Schema 校验；格式出错自动修复一次，失败则明确降级。

视觉理解与转录

支持图文视觉理解与视频语音转录，本地 faster-whisper 可无云端 ASR 凭据。

自定义分类

直接读取飞书「一级分类」字段选项，随时扩展自己的分类体系。

阅读状态管理

新内容默认「未读」，支持收件箱、未读、按分类浏览等视图。

开始使用

推荐使用 Docker Compose 部署。准备一个 PostgreSQL 数据库、一个飞书企业自建应用，以及一个 OpenAI 兼容的文本模型即可。

查看完整部署文档

配置示例：KW_DATABASE_URL · KW_FEISHU_APP_ID · KW_LLM_API_KEY · KW_LLM_MODEL
